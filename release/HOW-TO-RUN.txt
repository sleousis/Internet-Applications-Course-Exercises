Internet Applications Course Exercises
======================================

You need Java 17 or newer. Lab 1 and Lab 3 also need Apache Tomcat 11.
The examples use Tomcat on port 8080. Change the port in the URLs if yours differs.
On Windows use curl.exe and a semicolon as the classpath separator.

Lab 1: servlet web shop (lab1 zip)
----------------------------------
Copy myAskisisDir.war into Tomcat's webapps folder and start Tomcat.
Open http://localhost:8080/myAskisisDir/index.html in a browser.
The same flow with curl:

  curl -c cj -d "username=Savvas&product_service=products" http://localhost:8080/myAskisisDir/form_A
  curl -b cj -d "form_A=toys" http://localhost:8080/myAskisisDir/form_B
  curl -b cj --data-urlencode "form_B=a Doll" http://localhost:8080/myAskisisDir/form_C

The last page says "You have selected a Doll."

Lab 2: DOM, SAX and XSLT (lab2 zip)
-----------------------------------
Run these in the unpacked folder. Each program writes its result into the current folder.

  java -jar dom-navigator.jar generalXML.xml    (writes output.txt)
  java -jar sax-presentor.jar generalXML.xml    (writes output.txt)
  java -jar xsl-transformer.jar cars.xml        (writes cars.html)

The XSLT version with Xalan (use ; instead of : on Windows):

  java -cp xalan-2.7.3.jar:serializer-2.7.3.jar org.apache.xalan.xslt.Process -IN cars.xml -XSL cars.xsl -OUT cars.html

Lab 3: SOAP service (lab3 zip)
------------------------------
Create a folder called webapps-javaee inside the Tomcat folder and copy soap.war into it.
Start Tomcat. It converts the old javax web application to Jakarta EE and deploys /soap.
Then deploy the service and run the client from the unpacked folder:

  java -cp bvshop-client.jar org.apache.soap.server.ServiceManagerClient http://localhost:8080/soap/servlet/rpcrouter deploy BVCatalogDD.xml
  java -jar bvshop-client.jar http://localhost:8080/soap/servlet/rpcrouter Avensis Toyota 1937 Japan 2008

The client adds the vehicle and lists the catalog.
Keep the lib folder next to bvshop-client.jar.
